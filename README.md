# FloodReady MY

FloodReady MY is a citizen flood readiness support system built for the Citizens First (GovTech & Digital Services) track.

## Features
- Guided flood support
- e-KYC verification prototype
- Flood relief trigger dashboard
- Saved citizen profile
- Saved household details
- Saved document status

## Tech Stack
- Python Flask
- Google Gemini API
- HTML, CSS, JavaScript
- Google Cloud Run

## Local Setup
1. Create and activate a virtual environment
2. Install dependencies with `pip install -r requirements.txt`
3. Add your `GEMINI_API_KEY` to `.env`
4. Run `python app.py`
